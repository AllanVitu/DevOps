LoLFlow 🎮

Game Companion — LoL · Valorant · 2XKO

Un companion multi-jeux connecté à l'API Riot Games. Renseigne ta clé API, choisis ta région et analyse n'importe quel joueur sur League of Legends, Valorant ou 2XKO. La clé reste stockée localement (LocalStorage) et un proxy CORS gère les appels en production.

Architecture Technique

  • API Riot GamesRecherche et analyse de joueurs en temps réel sur 3 jeux.
  • Clé localeClé API stockée côté navigateur, jamais envoyée sur GitHub.
  • Proxy CORSCloudflare Worker pour contourner le CORS de l'API en production.
